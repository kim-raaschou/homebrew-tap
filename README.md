# homebrew-tap

Homebrew casks by kim-raaschou.

- [Mango Chutney](https://github.com/kim-raaschou/mangochutney): a tiling window manager for
  macOS, a port of the [mango](https://github.com/mangowm/mango) Wayland compositor.

  ```sh
  brew install --cask kim-raaschou/tap/mangochutney
  ```

- [AeroControl](https://github.com/kim-raaschou/AeroControl): a floating workspace overview
  for the [AeroSpace](https://github.com/nikitabobko/AeroSpace) tiling window manager.

  ```sh
  brew install --cask kim-raaschou/tap/aerocontrol
  ```
